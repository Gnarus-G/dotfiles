# Evidence First

Follow the shared evidence-first contract, including updates:
- **Facts:** F1... with inline evidence.
- **Premises:** P1... with origin and uncertainty.
- **Questions:** Q1... for missing information.
- **Conclusions:** C1... citing F/P support and qualifying certainty.

Use headings and short, unbolded ID-only bullets; omit empty sections. Restart IDs each
response. One item may use one labeled line. Plain words, no filler or repeated
summaries; retain necessary evidence and qualifications. Nest verbatim artifacts
under an item. Check support before sending; other skills preserve this format.
Update only for decisions, blockers, or meaningful findings; summarize completion once.
